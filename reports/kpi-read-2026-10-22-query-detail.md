## 1. ⚠️ 我上一轮读错了一处，先纠正

上一轮我把 `Citation Share` 解读为「该 query 占本站总引用量的比例」。本轮用 `Citations / 合计` 反算，**57/57 行全部对不上**，该解读被证伪。

正确口径是：**`Citation Share` = 本站在该 grounding query 上，相对全网所有被引站点的引用份额。**

证据链：
- 反算「全网总引用 = Citations / Share」，57 行全部满足 ≥ 本站引用数（0 行矛盾），合计推算全网总引用 22,417，中位数 95 / query，量级合理。
- `corr(引用量, 份额) = −0.276`，份额与体量无关甚至略负相关 —— 若它是本表占比，必须与引用量强正相关。
- 语义抽查完全吻合份额定义：泛词 `talent development` 引用 206 但份额仅 2.79%；独占词 `2026年7月绩效` 引用 42 份额 95.45%，`disc行为风格` 份额 100%。

**这个纠正会翻转结论方向**：按旧口径，高引用 query 是「主战场」；按正确口径，高引用 + 低份额是**红海，我们是边缘参与者**，不值得加码。

## 4. 结论（按可信度分层）

### 可下结论（有实测支撑）

1. **AI 引用的主战场被红海词吃掉了 58.2%。** `talent development` + `变革 ai` 两条就占 388 次引用（22.6%），但份额只有 2.79% / 2.97% —— 这两条上我们是被顺手带上的，不是被选择的。往这两条加码是低杠杆。
2. **真正可加固的是 A 象限 14 条。** `context not control`（63 次，三条拼写变体合计 127 次）、`腾讯活水`（47/56.63%）、`数字化原子能力`（35/45.45%）、`pod组织`（27/44.26%）—— 引用量与份额双高，是唯一值得追加投入的方向。
3. **C 象限有 5 条份额 100% 的独占词**，其中 `disc行为风格` / `disc风格` 两条合计 16 次引用、份额 100%，但站内只有 1 篇 DISC 测评文，且搜索侧 `disc是什么` 曝光 28 排名 4.8 零点击。DISC 是「AI 引用已独占但搜索转化失败」的最明确单点。
4. **搜索点击的问题在意图匹配，不在排名。** 56.8% 的 query 排名 ≤5，中位数 5.0，排名不是瓶颈；18 条排名 ≤6 且零点击才是瓶颈。

### 不能下结论（缺 page 级数据，硬下就是重犯历史错误）

- 「哪篇文章在贡献 AI 引用」—— 只能靠标题反查，无 citations-by-URL 字段，不做归因。
- 「该下线/该重写哪些页」—— 需要 page 级 citations 才敢判。
- 「P3 先做哪个簇」—— 目前只有 query 层证据，A 象限指向字节/腾讯/原子能力/Pod，但无法定位到具体页面动作。

### 需要补的表（请主理人在 Bing WMT 导出）

1. **AI Performance → Cited pages**（page URL + citations）—— 解锁全部 page 级归因，优先级最高。
2. KeywordReport 全量导出（当前只覆盖 12.4% 曝光），或明确其 top-N 限制值。

## 5. 数据卫生规则（写入纪律，避免下次重犯）

1. 任何 `Citation Share` 一律按**份额**解读，禁止按本表占比解读。复用本文件第 1 节反算校验（57/57 必不符 A 假设）。
2. KeywordReport 出现 `Clicks > Impressions` 的行一律按曝光上限修正后再合计，不得直接相加。
3. 两份 10/22 导出与 10/21 日表**窗口不一致**（日表 9/21–10/18，10/22 导出无日期列，推测为 28 天窗口但起止不同），覆盖率数字只作量级参考，不作精确对账。
4. 长串 prompt 类 query（25.1%）在算「需求结构」时单独标注，不与真实搜索词混算。
