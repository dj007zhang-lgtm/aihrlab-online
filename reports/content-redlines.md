# 作者绝不写 · 显式红线清单（content-redlines.md）

> 立标：2026-08-17。依据：内容宪法（基于事实 / 零虚构 / 不营销）+ ADR-20260817-001（门面≠脊梁）+ 学习素材 @jinchenma_ai「作者绝对不会写什么」。
> 维护机制：受 SDLC §3.1「维护即 retire」纪律约束——只增不减会打架；新增必合并冲突，过时即替换，禁纯堆积。
> 消费方：aihr-hardcore-writing skill Stage 5 L5 禁忌门直接读本文件逐条比对（单一真相源，skill 内不自建副本）。

## 0. 哲学

内容宪法的「基于事实、零虚构、不营销」是**原则**；本文件把原则落成**可机器 / 人工逐条比对的禁止项**，回答「作者本人绝对不会写什么」。它不替代 spine 与事实防线，而是它们的**下限兜底**：

- 不因为「文更好看 / 更营销」拔高或扭曲来源（T0 事实诚信）。
- 不因为「想显得有观点」编造经历、在场、或下判断（最高宪法第 3 条 / T3）。
- 不因为「想抓眼球」用营销腔 / 恐惧渲染 / 口号 spine（不营销红线）。

## 1. 红线清单（分类 · 每条：禁令 / 反例 / 依据）

### 1.1 事实诚信类
- **R-01 不为 slogan 拔高来源**：禁止用一句 catchy 口号 spine 扭曲期刊 / 作者实际结论（如把「探索性研究」写成「证实」）。依据：T0、ADR-20260817-001（slogan 仅门面，不得取代 spine）。
- **R-02 不编造数字 / 实体关系**：精确大额数字无出处不写；投资 / 股权 / 合作 / 任职关系须 WebSearch 核验，禁凭记忆拼凑。依据：T0、最高宪法补丁 A。
- **R-03 不把推测写死成事实**：推测性因果 / 结局 / 内部动机未标「判断 / 推测」不得写成既成事实；绝对化断言收敛为趋势判断。依据：T0、Stage 3 质量门。
- **R-04 不臆造具名场景**：禁止编造具名人物对话、「我在现场」式在场叙事来拉共鸣。依据：最高宪法第 3 条、T3。

### 1.2 营销腔类（不营销红线）
- **R-05 不写营销腔呼吁**：禁「点赞 / 在看 / 转发三连」式呼吁；结尾不甩锅、不演讲体升华。依据：不营销红线、反模式清单。
- **R-06 不制造焦虑叙事**：禁为表现解剖刀价值硬造宏大末日 / 恐慌（更危险 / 崩 / 凉 / 慌 / 末日）。依据：正见正念、0 恐惧渲染词。
- **R-07 不用口号 spine 替代脊梁**：slogan 可作门面定位，不得取代内容脊梁（135+ 硬信源深文才是脊梁）。依据：ADR-20260817-001。

### 1.3 权力叙事类
- **R-08 不道德审判 / 不贩卖恐惧**：停在机制解剖（权力 / 筹码 / 定价权 / 护城河），不给读者训诫。依据：最高宪法第 2 条。
- **R-09 不居高临下**：承认读者处境复杂性（对立面同理心），不把读者当需要被教育的对象。依据：声音温度 T-技4。

### 1.4 风格绑架类（语域纪律）
- **R-10 不用物理借词框架**：禁路由器 / 高阻抗 / 熵增 / 固态液态充当组织解释框架，用纯 OD 语言。依据：Stage 3 质量门。
- **R-11 不文学诗意隐喻**：禁母语作废 / 方言 / 音节类诗意隐喻；机制隐喻只跑一套体系。依据：最高宪法补丁 B。
- **R-12 不破执行纪律**：破折号须规范（非禁用）、H2 无句末标点、数字中文半角空格、裸英文术语保留。依据：补丁 C。

### 1.5 结构类
- **R-13 不一稿多论平铺**：一篇一论，禁把多论点做成平铺综述巡礼（证据编织进正文作注脚，不抽空成卡）。依据：T6。
- **R-14 不为去生硬跨红线**：为「显得活」而引入粗口 / 表情包标点 / 恐惧词 / 营销腔＝矫枉过正丢人格。依据：声音温度边界。

### 1.6 调性/品味类（2026-08-18 立）
- **R-15 h2/h3 不自标数据出处**：节标题禁贴「据X源」「（公开资料整理）」「（一手数据）」「（权威研究）」「（可信来源）」「（核验）」「（数据来源）」等自标标签。专业作者让底部参考信源块自己说话，不在标题里表演可信度。依据：用户 2026-08-18 反馈「据2026一手信源这些都是无用的不专业的废话」+ 全站 48 篇清扫实证。机检：`scripts/taste_gate.py` `gate_self_label`。
- **R-16 正见正念底线（2026-08-25 立）**：文章不得借恐惧/焦虑/升华/呼吁牵引读者；不得用口号spine替代脊梁；不得为「正向」拔高来源扭曲结论。依据：用户 2026-08-25 明确「质检agent务必把好文章质量和方向门。正见正念的弦要紧绷」。机检：Gate14读者视角（营销红词检测）+ stability_guard S6真实性 + content-redlines R-05/R-06/R-07/R-14 共同兜底。AI 自主预判偏差并主动纠偏，不等待用户发现。
