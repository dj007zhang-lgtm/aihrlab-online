## 2. 第一性原理：为什么「简报」形态是错的

v1 设计的机制是「增加可引用锚点数量以拉低 GEO 集中度」。这个机制本身成立，但**载体选错了**：

| 简报形态（v1） | 后果 |
|---|---|
| 每期 5–8 条独立短单元，时间序、彼此无关 | 一年 26 期 = 26 个孤立薄页。**薄页在 GEO 中权重低于厚页**，且时间序内容 18 个月后无人引用 |
| 每期从零写 5 条新信号 | 单作者 + 一手信源核验，双周必然逼出凑数——凑数是品味的死因 |
| 内容为「外部发生了什么 + 我怎么看」 | 本质是**信息整理**。主理人文风纪律里，「信息整理」是明令禁用项；做成 recurring 等于把最大的文风雷区常态化 |
| 可引用单元随期数线性增长 | 集中度分母变大 → 数值下降，但那是**稀释**，不是权威分散。KPI 数字达标、实质未改善，正是汇报口径铁律要防的东西 |

**本站真正的资产不是信源，是判断。** 300 篇文章每篇都含一个判断，但判断**不可累加、不可追新、不可修订**——读者和 AI 引擎只能整篇取用，取完就走。这是「库存丰富、锚点稀缺」的根。

所以策展要造的不是一个更快的信源管道，而是**判断的时间结构**。

## 3. 提案：信号线台账（Signal Ledger）

### 3.1 三层结构（全部静态、可索引、零后端）

| 层 | 落点 | 形态 | 职责 |
|---|---|---|---|
| **线**（Line） | `/brief/lines/<slug>.html` | 长期存在的单页，随证据增厚 | 追踪**一条可证伪的判断**，是真正的可引用单元 |
| **期**（Issue） | `/brief/<NNN>.html` | 双周，极短 | 只报**本期哪几条线有新证据/被翻转**（增量 diff），不重写内容 |
| **索引** | `/brief/index.html` | 常驻 | 按主题域分组的线清单 + 状态分布 + 最新一期入口 |

### 3.2 线页契约（页面必须包含以下五块，缺一不可）

1. **当前判断**：一句话，可证伪，带最近修订日期。例：「组织扁平化的收益存在规模边界：AI 团队过约 7000 人后，协调成本反超精简收益。（2026-10-16 修订）」
2. **状态标签**：`稳固` / `被挑战` / `已翻转` / `归档`（归档须写明停止追踪的理由）
3. **证据时间线**：倒序，每条 = `日期 + 一手源（可点）+ 一行事实 + 它支持还是削弱这条判断`。**削弱证据必须收录**——这是过滤器信誉的来源
4. **本站挂接**：相关长文 / 测评 / 枢纽（只用站内公开资产，不交叉引用付费内容）
5. **JSON-LD**：`Article`（含 `datePublished` / `dateModified`）+ 证据条目 `ItemList`（每条含 `datePublished` / `url` / `text`）

### 3.3 状态机与「翻转」纪律

```
新建 → 稳固 ⇄ 被挑战 → 已翻转 / 归档
          ↑____________|
```

- 出现反证时**不得删改原判断句**，改写为「原表述 + 失效条件 + 修订日期」。读者要能看到这条判断是怎么变的。
- 「已翻转」不是失败。一个敢记录自己判断被推翻的过滤器，才配叫过滤器。

### 3.4 期页纪律

期页本体**极短**：主编视角一句（≤3 句，必须是判断不是总结）+ 本期变动表（线名 / 状态变化 / 新增证据条数 / 链接）。
所有实质内容在线上累积，期页只是索引增量。**这一条把「信息整理」从产品形态里结构性排除掉了。**

## 4. 与既有资产的三条接口

| 接口 | 机制 |
|---|---|
| 线 → 长文 | 某条线证据厚度足够（≥5 条一手证据、跨 ≥2 个季度）→ 升级为旗舰长文。策展是雷达，长文是深潜 |
| 长文 → 线 | 长文中的判断落到对应线上，后续新证据可更新它。**判断可被后续证据修订**——这是绝大多数内容站做不到的 |
| 线 → 测评 | 若「Now What」指向自我认知/组织角色类动作，可挂测评（AI 替代风险 / DRI 成熟度）。雷达 → 自测闭环，零变现 |

## 5. 边界：桥（bridge）怎么办

三个处置选项与代价：

| 选项 | 动作 | 代价 / 风险 |
|---|---|---|
| A（建议） | 策展导航改指 `/brief/`；`/bridge/` 页摘掉撮合叙事，降级为「能力标准项目进展」占位页 | 需改 351 个页面的导航（脚本批量，一次到位） |
| B | `/bridge/` 直接下线，导航改指 `/brief/` | 页面有历史外链与索引，删除会造 404 |
| C | 保留现状，策展入口另加 | 一个导航位两个含义，读者与引擎都困惑，等价于没做 |

**推荐 A**，并明确「推荐罗盘」的排期：等能力模型标准层通过校验（P1 完成、SHRM 一手核验落地）后再做。把未定稿的标准做成产品，等于把未验证的判断固化成对外承诺。

## 6. 产能模型（双周可持续的前提）

| 形态 | 每期工作量 | 品质风险 |
|---|---|---|
| v1 简报：写 5–8 条新信号 | 约 2 小时，且从零起步 | 高（凑数） |
| v2 台账：给 3–5 条已有线各追加 1 条证据 | 约 40 分钟，且有上下文 | 低（在已有判断上加证据，天然聚焦） |

产能降下来的同时品质上升——这是复利结构相对消耗品结构的决定性优势。

## 7. KPI 勾连（机制而非口号）

| KPI | 基线 | 机制 |
|---|---|---|
| GEO 集中度 85.8% → <50% | 85.8% | 分散的是**持续增厚的厚页**（长期 20–40 条线），不是薄页。引擎偏好有历史纵深、有日期、有一手出处、有明确立场且持续更新的页面 |
| 跳出率 96.59% → <85% | 96.59% | 每条线挂接长文 + 测评，形成二跳出口；期页 → 线 → 长文 三段式 |
| Bing 曝光 1750 → 5000/周 | 1750 | 线页是新增可索引 URL 且主题聚焦，命中长尾聚合查询 |

## 8. 验收信号（不接受「做了」）

| 信号 | 怎么验（可脚本化） |
|---|---|
| 策展不再孤儿 | `/brief/` 全部 URL 进 sitemap；≥300 个页面的「策展」导航指向 `/brief/` |
| 线页是真台账 | 线页含 5 块契约元素；含 `dateModified`；证据条 ≥3 |
| 不再有撮合叙事 | 全站扫 `/bridge/`：撮合/对接/投递 类词计数 = 0 |
| 复利而非稀释 | 期页正文 ≤ 期页总字数的 30%（增量为主，实质在线上） |
| 判断可修订 | 至少 1 条线含「被挑战」或「已翻转」历史记录 |
