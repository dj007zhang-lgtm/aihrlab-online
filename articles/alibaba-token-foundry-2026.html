阿里成立TokenFoundry：吴泳铭直管AI商业化

把模型能力收进一个 CEO 直管的产能单元，阿里这步棋的真正含义是让 Token 变成商品。

核心结论

阿里 2026 年 11 月初（AASTOCKS 11 月 5 日报道）合并通义大模型事业部与未来生活实验室，成立 Token Foundry 事业部，由集团 CEO 吴泳铭直接负责。这一步不是又设一个 AI 部门，而是把模型能力变成可计价的商品，并把这条生产线的指挥权收到 CEO 手里。它和腾讯减法、字节 Seed 收编、微软 VEO 是同一道题的不同写法：当 AI 从研发投入转向商业回报，组织的重心从谁在做模型挪到谁能把 Token 卖出去。

创造 Token、输送 Token、应用 Token。

阿里巴巴 ATH 事业群内部目标逻辑，据界面新闻 2026 年 11 月 3 日报道

从分散实验室到 CEO 直管的 Token 工厂

2026 年 3 月 16 日，吴泳铭通过内部信成立 Alibaba Token Hub（ATH）事业群，由他直接负责，下设通义实验室、MaaS 业务线、千问事业部、悟空事业部与 AI 创新事业部共五个事业部。这一步解决的是协同成本：此前模型、服务、应用分属不同汇报线，资源重复、节奏错位。4 月 8 日，通义实验室升级为通义大模型事业部，由周靖人负责，阿里第一次把基础模型研发摆到集团级事业部的位置。

11 月 5 日（AASTOCKS 报道）的动作是进一步的收口：合并通义大模型事业部与未来生活实验室，成立 Token Foundry 事业部，仍由吴泳铭直接负责。周靖人转任阿里巴巴首席科学家，牵头成立阿里巴巴 AI 未来研究院，专注前沿探索；郑波带领 Happy Horse、Happy Oyster 等团队并入新事业部。把模型研发与视频、多模态应用两条汇报线收进同一个 CEO 直管的产能单元，这正是这步棋的落点：不是增设部门，而是压缩跨线协同成本，并把指挥权上收。

名字本身就是组织宣言：Token 工厂

Foundry 一词本意是铸造厂、金属加工厂。阿里把它和 Token 拼在一起，意图很清楚：要做 AI 时代的 Token 工厂，当基础供给方。对照同行的位置，这条路线更具体：英伟达卖铲子，每一枚 Token 的生成都要烧它的 GPU；OpenAI 卡模型层，把最强模型能力锁在 API 后面，从 ChatGPT 到 Codex 在自有平台闭环；Anthropic 卡基础设施，用 MCP 协议与 Claude Code 把能力沉到工具链。阿里选的位置，是把模型与应用能力封装成可计价的 Token 商品，对外供给、对内计价。

这一步把能力变成商品，对应的必然是考核与激励口径的迁移：从研发投入、论文与榜单，转向 Token 被调用、被付费、被复购的比例。名字里写进 Foundry，等于把商业化从隐含目标变成事业部的第一身份。

商业化的第一枪：把 Token 摆上货架

这次组织动作之所以不像一次普通架构微调，是因为它和市场动作几乎同步发生。11 月 2 日晚，千问办公 CEO 陈宇森坐进李佳琦直播间，把原价每月 28 元的千问办公基础版月卡以 0.01 元上架，半小时卖出 10 万份，对应约 2 万亿 Token。Token 第一次从模型计费单位，变成可以摆在货架上的商品。

11 月 4 日，国行版 Apple Intelligence 首次开放测试，千问接入，在 Siri、写作工具与视觉智能等入口提供文本与图像理解能力。这两步合起来说明，Token Foundry 不是一个研究单元，而是一个带着商业化 KPI 直接冲向用户的产能单元。它要回答的不是模型跑分，而是 Token 能不能被卖出去、被用起来。

和腾讯、字节、微软是同一道题

把视野拉到同周期的大厂，会发现这是同一道题的不同写法。腾讯做减法，把元器、QClaw 的算力压向核心赛道；字节把验收与安全单列成一级部门，把验证能力写进编制；微软用 VEO 把人换算力，把 HC 从人头计数转向资本支出计数。阿里这一步的特点，是把商品化显式写进事业部名字，并把指挥权收到 CEO 手里。

共通逻辑只有一条：当 AI 能力趋于同质，竞争焦点从模型参数规模，转向推理成本、数据壁垒与杀手级应用场景，组织也随之从研究优先转向商业优先。谁先把模型能力变成可计价、可复购的商品，谁就在下一阶段的组织效率上占先。阿里用 Token Foundry 把这条逻辑写进了建制。

对 HR 的硬判断：编制、考核与激励怎么跟着改

第一，编制口径从人头计数转向产能单元计数。Token Foundry 是一个把模型、视频、应用捏在一起的产能单元，HR 排 HC 时看的不再是岗位名称，而是这个单元能稳定产出多少被使用的 Token。编制表要从岗位清单，改成产能清单。

第二，考核从榜单转向 Token 商品化率。论文、跑分、开源排名是投入侧指标，真正该计量的是 Token 被调用、被付费、被复购的比例。把这一栏从研发侧挪到经营侧，组织的注意力才会从做出来转向卖出去。

第三，激励从项目奖金转向内部市场化。参考行业里交易、夹层、跟投三种定价关系，让中台能力明码标价、按次计费，有价值的产能被买单，价值不足的被外部供应商替代。这一步让躲在中后台变成高成本的事。

三个边界不能忽略。阿里有电商与云的规模底盘，多数公司没有这个体量，先拿能否被计价当作冗余识别器，而不是照搬事业部建制；需要存在吸收产能的真实业务网络，否则产能无处落地；需要前沿研究与商品化之间留有制衡，否则商品化 KPI 会反过来挤压长周期探索。周靖人转去牵头 AI 未来研究院，正是这一制衡的设计，效果仍待观察。

三个待验证的疑问

合并能否真正降低协同成本，还是只换了一块牌子。把两条汇报线捏进一个事业部，省下的是会议与对齐，丢掉的可能是专业纵深，这要在下一个季度的交付节奏里看。

商品化 KPI 会不会反过来挤压前沿研究。AI 未来研究院是制衡设计，但当一个事业部以 Token 商品化率为第一指标，长周期、低确定性的探索很容易被排在后面，这是所有研究型组织都绕不开的张力。

把 Token 当商品卖，能否跑通可持续单价。开源模型持续压价的大环境里，Token 单价长期下行，靠规模换收入的前提是真实的调用与留存，而不是一次直播间的脉冲。这条线的成色，要在双11之后再看。
