McKinsey 7S 组织一致性自测

七个维度、各三题，量化你的组织在「硬要素（战略 / 结构 / 制度）」与「软要素（价值观 / 风格 / 人员 / 技能）」之间的对齐程度，即时出分与对齐建议。

📊 使用说明
1. 每题按 1–5 打分：1 = 完全不符合，5 = 完全符合（分越高＝该要素越到位）。
2. 七个维度各 3 题，维度得分＝该维度 3 题平均分；总一致性＝七个维度得分的等权平均（各占约 14.3%）。
3. 总分映射到三档：< 2.8 一致性偏低 / 2.8–3.7 初步对齐 / ≥ 3.7 高度对齐。
4. 建议由 HR + 业务一号位共同评，或多人独立评后取均值，避免单人偏差。

逐维度明细

优先对齐建议

    这个工具在解决什么

    「我们的组织是不是一个对齐的整体」是变革里最难凭直觉回答的问题——因为战略写在 PPT 上，结构落在组织架构图里，而真正起作用的是看不见的价值观、风格与技能。McKinsey 7S 组织一致性自测把组织拆成七个彼此咬合的要素（硬三S：战略 / 结构 / 制度；软四S：共享价值观 / 风格 / 人员 / 技能），让你在同一张表、同一套口径下看到「哪里对齐、哪里撕裂」，而不是被局部成功迷惑。

    如何使用

    • 适用对象：正在或计划推进组织变革（含 AI 转型）的团队。
    • 谁来打：HR + 业务一号位共同评，或多人独立评后取均值，避免单人偏差。
    • 打分：每题 1–5，按该描述在组织当前真实状态打原始分。
    • 出结果：点「计算一致性」，立即得到总分、等级与逐维度明细、对齐建议。
    • 复用：可把本页打印或截图，用于组织诊断会 / 架构复盘会。

    为什么有效

    7S 模型由 Tom Peters 与 Robert Waterman 在麦肯锡时期（1980 年代初）提出，其核心洞见是：组织有效性来自七个要素的相互对齐，而非单一要素的优化。其中「共享价值观」是圆心——战略、结构、制度都要围绕它，而风格、人员、技能是支撑它的软要素。本自测把七要素等权（各约 14.3%），是因为任一要素的明显短板都会拖累整体对齐；阈值（2.8 / 3.7）是便于落地的经验切分，应结合组织规模与行业校准。

    变体

    • 部门对比版：对各业务单元分别评分，识别「先对齐 / 先补课」的单元。
    • 并购前体检版：并购或大规模重组前自评，预判整合阻力点。
    • 季度追踪版：每季度复评，验证变革投入是否转化为一致性。
