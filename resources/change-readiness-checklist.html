变革就绪度诊断 v1.0

组织变革准备度诊断清单

把 Kotter 8 步、ADKAR 与 McKinsey 7S 揉进一张可勾选、可自评的清单，输出组织当前变革就绪度与优先加固项。

📋 使用说明
1. 每个条目左侧勾选框＝你认为「本项已落地 / 已具备」（快速落地率用）；右侧滑块＝该项的成熟度自评（1 最弱 → 5 最强）。
2. 三个框架（Kotter 8 步 / ADKAR / McKinsey 7S）共 20 项，覆盖从「为什么变」到「如何锚定」的全链路。
3. 点「计算就绪度」得到总分（1–5）、快速落地率与各框架短板；任意短板框架即优先加固对象。
4. 点「打印 / 导出 PDF」可生成会议用诊断底稿。

各框架就绪度

优先加固项

    这个工具在解决什么

    「我们的组织准备好变革了吗」是一个横跨战略、个体与组织三层的复杂问题，单看一个模型都会失真。组织变革准备度诊断清单把三个被最广泛验证的变革框架——Kotter 8 步（推进节奏）、ADKAR（个体状态）、McKinsey 7S（组织一致性）——揉进一张可勾选、可自评的清单，让你在同一张底稿上看到组织变革就绪的全貌，而不是各拿一套语言各自为战。

    如何使用

    • 适用对象：正在或计划推进组织变革（含 AI 转型）的团队（建议变革推动者 + 业务一号位共评）。
    • 勾选：左侧勾选框标记「本项已落地」，用于快速落地率。
    • 自评：右侧滑块对每项成熟度打 1–5 分。
    • 出结果：点「计算就绪度」，得到总分、快速落地率与各框架短板。
    • 复用：点「打印 / 导出 PDF」生成会议底稿；对勾选项优先排期落地。

    为什么有效

    三个框架分别回答变革的不同问题，互为补充：

    • Kotter 8 步回答「怎么把变革推起来、不断档」——提供节奏与里程碑。
    • ADKAR回答「个体为什么不变、怎么让他变」——变革最终发生在每个人身上。
    • McKinsey 7S回答「组织各部件是否彼此对齐」——战略再好，结构 / 制度 / 技能不支撑也会落空。

    任一框架成为短板，都会成为变革的瓶颈：Kotter 推进了但 ADKAR 个体没跟上，会变成「领导在跑、员工原地」；7S 不一致则让试点成果无法扩散。阈值（总分 < 3.0 视为需重点加固）是便于落地的经验切分，应结合变革阶段校准。

    变体

    • 启动前基线版：变革立项时自评一次，作为基线。
    • 季度复盘版：每季度复评，观察短板框架是否改善。
    • 单元对比版：对各业务单元分别评，识别最该先扶的单元。
