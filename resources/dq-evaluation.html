企业级 AI 可替代岗位评估表

从四个维度量化评估每个岗位的 AI 替代风险，浏览器内直接打分、即时出结果。

📊 使用说明
1. 为组织架构中的每个关键岗位填写本打分卡（建议由 HRBP + 直属上级共同评分）。
2. 每题打分 1–5：1 = 完全符合 / 高度同意，5 = 完全不符合 / 几乎不发生（所有维度同向评分，分低 = 易替代）。
3. 维度得分 = 该维度下 4 题平均分；总分 DQ = ①×30% + ②×25% + ③×25% + ④×20%。
4. DQ < 2.0 → 🔴 高风险，建议 12 个月内启动 AI 替代计划；DQ 2.0–3.5 → 🟡 中风险，混合模式；DQ > 3.5 → 🟢 低风险，重点能力提升。 💡 评分锚点：1 分 = 该描述在每日工作中出现频率 ≥ 80%；5 分 = 该描述几乎不发生（≤ 10%）。维度②③④由系统在计分环节统一翻转，你只需按真实频率打原始分。

    这个工具在解决什么
    
  
    「哪些岗位会被 AI 替代」是组织规划里最容易情绪化、也最容易拍脑袋的问题。DQ（Displaceability Quotient，可替代商数）评估表把它变成一个可重复、可比较的量化动作：用四个彼此正交的维度刻画一份工作的「可机械化程度」，让 HR 与业务一号位在同一张表、同一套口径下讨论替代优先级，而不是各凭直觉。
    

  
    如何使用
    
  
      
    
    • 适用对象：组织架构中的关键岗位（建议从人数多、成本高的岗位切入）。
      • 
    
    • 谁来打：HRBP + 直属上级共同评，避免单人偏差；每个岗位单独一张卡。
      • 
    
    • 打分：每题 1–5，按该描述在每日真实工作中出现的频率打原始分，系统自动翻转反向维度。
      • 
    
    • 出结果：点「计算 DQ 总分」，立即得到总分、风险等级与逐维度明细、行动建议。
      • 
    
    • 复用：可把本页打印为纸质打分卡，或截图结果用于组织盘点会议。
      • 
  
    

  
    为什么有效
    
  
    四个维度对应工作被 AI 替代的四条「护城河」：
    
  
      
    
    • 流程标准化（权重 30%）：SOP 越清晰、输出越可量化验收，越容易被流程自动化 / Agent 接管——这是替代的第一道门槛。
      • 
    
    • 决策复杂度（25%）：模糊信息、多目标权衡、组织政治隐性知识，是当下大模型最不稳定的区域。
      • 
    
    • 情感交互密度（25%）：情感劳动（共情、信任建立、情绪安抚）与「真人回应」期待，是用户对 AI 接受度最低的环节，也是 HR、管理者类岗位的核心壁垒。
      • 
    
    • 创造性需求（20%）：无模板的新方案、跨领域整合、重新定义问题本身——这类任务短期内更适配「AI 增强人」而非「AI 替代人」。
      • 
  
    
  
    权重反映了一个经验判断：流程可标准化是替代的充要条件中最先被满足的，故给最高权重；其余三项是「难替代」的叠加保护，按对组织价值的贡献递减赋权。区间阈值（2.0 / 3.5）是便于落地的经验切分，应结合行业与岗位层级校准。
    

  
    变体
    
  
      
    
    • 个人自检版：把「岗位」替换为「我的日常工作」，用于个人判断哪些任务该交给 AI、哪些能力要重点投资。
      • 
    
    • 团队矩阵版：对部门内所有岗位批量评分，按 DQ 降序排列，输出「优先替代 / 混合 / 增强」三档清单。
      • 
    
    • 招聘反推版：用低 DQ 维度反推「这个岗位该招什么样的人」——重点考察决策、情感、创造三项。
