## V-09 的边界（必须写清，否则是假校验）

V-09 只能做**台账自校验**：它盯的是「本地台账有没有如实记录已迁/未迁」，防的是台账标 LIVE 而实际没迁。

**真实的空间归属无法离线判定**——脚本不持有乐享凭证，也不调 MCP。所以 V-09 之外必须配一条人工核验，且每次迁移后写入本表：

| 核验项 | 执行者 | 状态 |
|---|---|---|
| `space_list_spaces(team_id=AIHR)` 返回空 → 该团队下无知识库 | AI（API 实跑） | ✅ 已确认 2026-09-19 |
| MCP 侧无创建知识库接口 → 建库为账号所有者独占动作 | AI（工具清单实跑） | ✅ 已确认 2026-09-19 |
| 知识库创建 + 镜像迁入 | **主理人 + AI** | ✅ 2026-09-21 主理人建库（space `df7ca476…`），AI 迁入 8 条目并经 entry_list_children 核验 |

## 已修的校验自身缺陷（错不二犯）

| 问题 | 根因 | 修复 |
|---|---|---|
| 首轮实跑 4 个 FAIL 中 3 个为假 | `SITE` 路径少算一级，`dirname(ROOT)` 得到 `projects/` 而非站点根，导致 V-02、V-07 假失败，V-01 扫错目录却假 PASS | 路径改上溯两级 |
| 同上问题可能复发且不易察觉 | 无自检 | 新增 **V-00 哨兵**：SITE 必须含 `sitemap.xml` 与 `articles/`，否则后续结果全部不可信 |
| V-03 命中校验脚本自身 | 关键词表写在脚本源码里，被自己扫到 | 扫描时排除 `SELF` |
| 修 V-02 时叠出两个「延伸阅读」区块 | 补丁前没读工作区当前状态，上一轮已加好但未落 commit 的改动被当成不存在 | 新增 **V-02b**：同一测评页 `ext-read` 区块不得 >1；纪律固化为「补丁前先 diff」 |
| 项目早期无镜像被判 FAIL | 状态机只有 PASS/FAIL | 引入 `SKIP` 态，P1 起转必检 |

**纪律**：校验脚本自身必须先被校验。首轮若不实跑，会拿「4 个 FAIL（3 假）」和「1 个假 PASS」交差，比不校验更坏。
